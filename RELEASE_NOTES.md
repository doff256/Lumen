Lumen 1.3.0 can turn all displays off with a configurable global shortcut.

- Press Ctrl + Alt + O, choose **Turn displays off** from the tray menu, or use the button in Settings. Windows requests display power-off without sleeping the PC. Mouse or keyboard activity wakes the displays again.
- Click the shortcut field in Settings and press Ctrl + Alt with a letter or F1–F12, optionally with Shift, to rebind it. The shortcut can be disabled independently of the brightness shortcuts. If registration fails, Lumen restores the previous shortcut and reports the conflict.
- The popup now resizes when a Settings section is expanded, including in the hidden Electron preview.

Download the portable EXE or extract the ZIP and run Lumen.exe. Enable DDC/CI in external monitor settings. Windows display power behavior varies by monitor and driver.

**Signing:** these builds remain unsigned. [Code signing policy and SignPath enrollment requirements](https://github.com/doff256/Lumen/blob/main/docs/code-signing.md). SignPath approval and owner setup are still required; no signing application has been submitted on the owner's behalf.
